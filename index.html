Publier sur VibePulse

Colle un lien YouTube (il sera lu directement) ou le lien direct d'un fichier vidéo déjà hébergé.
Tu indiques simplement la chaîne. VibePulse vérifie les vidéos publiques disponibles via YouTube Data API v3, évite les doublons et les intègre sans télécharger les fichiers. Les miniatures sont chargées à la demande pour éviter les ralentissements.
TikTok ne fournit pas d'API publique permettant d'aspirer automatiquement « toutes les vidéos » d'un compte quelconque : seule l'intégration officielle (oEmbed) vidéo par vidéo est disponible sans accord de partenariat. Colle ici les liens des vidéos que tu veux afficher.

💡 Pour un stockage illimité et gratuit, configure ton propre compte cloud gratuit (voir CLOUD_CONFIG en haut du script). Sans configuration, les fichiers restent stockés dans ton navigateur (limité).
